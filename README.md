## What is GameHub?

GameHub puts every game you own, whichever launcher it lives in, in **one clean library**. Click a poster and the game
starts: no hopping between Steam, Epic, Ubisoft, Riot and Rockstar.

| | |
|---|---|
| **One library** | Steam, Epic Games, Ubisoft Connect, Riot and Rockstar games with cover art, found automatically |
| **One-click play** | Games start through their own launcher in the background, no launcher window in your way |
| **Live update status** | See which games are updating, with a real-time progress bar (Steam) |
| **50+ apps** | Add Discord, Spotify, OBS, Roblox, Modrinth, CurseForge, Lunar Client, FL Studio, Brave and more, each with its own page |
| **Make it yours** | Four built-in themes and a Theme Studio to change every colour, font, shape and effect, then save your own |
| **Your layout** | Reorder, hide or delete anything in the sidebar and the filter bar |
| **Secure updates** | New versions arrive by themselves, signed so only the author can ship them |

## Install

1. **[Download GameHub-Setup.exe](https://github.com/Khxn-alt/gamehub-releases/releases/latest/download/GameHub-Setup.exe)**
2. Run it and follow the steps (no administrator rights needed)
3. Open GameHub from your Desktop or Start menu. Your games appear automatically

> **Windows SmartScreen** may say "unknown publisher" the first time, because the installer is not signed with a paid
> certificate. Click **More info → Run anyway**.

**Updates** are automatic: GameHub checks for a new version on start and shows an *Update now* banner (or installs it
by itself if you tick *Install automatically* under *Terms & FAQ*). Every update is cryptographically signed by the
author and is refused if anything was changed.

**Uninstall:** Windows Settings → Apps → GameHub.

## FAQ

<details><summary><b>Does GameHub ask for my passwords or log in to my accounts?</b></summary>

No. It never asks for or stores credentials. It reads what is already installed on your PC and starts games through each
launcher's own link, like a desktop shortcut would.
</details>

<details><summary><b>Is it free? Is it open source?</b></summary>

GameHub is free to use for personal, non-commercial use. It is **not** open source: copying, redistributing or reusing
its code, design, themes or logo is not allowed (see below).
</details>

<details><summary><b>Where is my data stored?</b></summary>

Locally, in <code>%APPDATA%\GameHub</code> (favourites, theme, layout). Nothing about you is sent to the author. To show
artwork and genres it requests public info from the Steam store and Wikipedia.
</details>

<details><summary><b>Why does a game show "Update available"?</b></summary>

GameHub reads Steam's local update status, so Steam is accurate, including progress. Epic only shows incomplete installs;
Ubisoft and Riot update when you start the game.
</details>
